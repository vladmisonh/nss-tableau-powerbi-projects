\# Data Visualization Projects – Tableau \& Power BI



Welcome to my repository, which contains \*\*Tableau\*\* and \*\*Power BI\*\* projects completed as part of my Data Analytics portfolio. These projects showcase my ability to transform raw datasets into \*\*interactive dashboards\*\* and \*\*compelling visual stories\*\*, providing actionable insights through modern data visualization tools.



\## Overview



The projects in this repository highlight my skills in \*\*dashboard design, data storytelling, KPI tracking, and interactive analytics\*\*. Each visualization is based on real-world datasets and focuses on presenting trends, comparisons, and key performance metrics in a clear and visually engaging way.



\## What You’ll Find Here



\### Key Projects:



\* \*\*Netflix Content Analysis (Tableau)\*\* – Dashboard analyzing Netflix’s movie and TV show catalog by country, ratings, top titles, and duration.

\* \*\*Soft Drink Sales Analysis (Tableau)\*\* – Sales performance dashboard tracking revenue, profit, top products, customers, and geographic distribution.

\* \*\*Car Accidents Analytics 2015–2022 (Power BI)\*\* – Interactive accident analysis by year, month, weekday, location, weather, and collision type.



\### Skills Demonstrated:



\* Building \*\*interactive dashboards\*\* in \*\*Tableau Public\*\* and \*\*Power BI\*\*.

\* Designing clear and \*\*KPI-focused reports\*\* to track performance over time.

\* Creating \*\*geospatial visualizations\*\* to map trends by location.

\* Using filters, parameters, and slicers for dynamic data exploration.

\* Combining multiple chart types – bar charts, line charts, maps, donut charts – to tell a complete data story.

\* Applying \*\*data cleaning and preparation\*\* in Excel before visualization.



\## Tools \& Technologies Used



\* \*\*Tableau Public\*\* – Data visualization and dashboard publishing.
