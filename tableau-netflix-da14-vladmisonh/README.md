# Netflix Shows & Movies Analysis – Tableau Dashboard

This project explores Netflix’s global content library using data from [Kaggle’s IMDB Dataset](https://www.kaggle.com/datasets/sarahjeeeze/imdbfile). The analysis was conducted in **Tableau** as part of my ongoing data visualization practice, focusing on identifying trends in content distribution, ratings, and show characteristics.

---

## Project Overview

The dataset includes detailed information on Netflix shows and movies, such as:

* **Title**
* **Type** (Movie or TV Show)
* **Country of Origin**
* **IMDB Rating**
* **Duration**
* **Release Year**

Using Tableau, I built an **interactive dashboard** to answer questions like:

* How many shows and movies are available on Netflix, and what is the ratio between them?
* Which countries have the highest number of Netflix titles?
* What is the average IMDB rating for movies vs. TV shows?
* Which are the top-rated Netflix titles?
* What are the longest-duration shows and movies?

---

## Tools & Technologies Used

* **Tableau Public** – For data visualization and dashboard creation
* **Microsoft Excel** – For initial data exploration and cleaning
* Data source: Kaggle IMDB Dataset ([link](https://www.kaggle.com/datasets/sarahjeeeze/imdbfile))

---

## Dashboard Features

The Tableau dashboard includes:

1. **Total Shows and Movies** – Pie chart comparing the number of movies vs. TV shows
2. **Average Rating** – Bar chart showing average IMDB ratings for each type
3. **Show Number by Country** – World map highlighting title distribution
4. **Top Rated Shows by IMDB** – Horizontal bar chart ranking the highest-rated titles
5. **Show Duration** – Visualization of the longest titles in minutes
